# 真实浏览器验收清单

使用单独的测试项目和本机 `node server.mjs`，先导出需要保留的旧项目。常规 `node --test` 不替代这里的真实浏览器与工具链验证。

1. **默认可视化编辑**：打开完整 LaTeX 文档应直接显示可编辑纸面。直接修改标题、正文，用工具栏加粗及调整标题级别，双击现有公式修改并用 Ctrl/Cmd+Enter 确认；应保持编辑区，不能误触发编译。切到其他文件再返回应保留改动和明确选定的模式；刷新仍默认打开可视化。
2. **完整编辑**：修改项目名称，立即切换文件、编辑，再刷新。名称和源码应恢复。新建 `sections/method.tex`，输入章节与 `\label`；新建/重命名弹窗的确认与取消都应工作，即使宿主不支持原生 `prompt`。
2. **查找与历史**：替换章节中的一句话，撤销后恢复原文，重做后恢复新文。切换其他文件不应混用历史。
3. **多文件与引用**：主文档用 `\input{sections/method}`、`\ref` 和 `\cite`，参考文献写入 `.bib`。切换可视化再返回源码，导言区和引用命令应保留。
4. **主文件**：选择 `.ps` 并设为主文件，编译目标应同步；手动更改编译目标后，普通编辑不应重置目标。对原主文件再次点击「设为主文件」仍应切回该文件。
5. **LaTeX 编译与下载**：编译主文档，检查实际页面文字、中文、编号和文献。导出 PDF 后用 PDF 阅读工具确认页数与文本，不能只检查 HTTP 成功状态。
6. **修改后导出**：先编译成功，再修改章节文本。预览应显示旧结果提示；直接点击「导出 PDF」应先重新编译，下载文件须包含新文本。
7. **PostScript**：输入两页 PS，分别绘制矩形和圆形并写入不同页标题。渲染后使用下一页和上一页，页码、图片与标题均须一致；导出 PDF 必须包含两页。
8. **错误与取消**：缺少 `\input` 文件时应显示编译错误与日志，源码仍可改；输入 `%!PS\n{} loop` 后取消，随后恢复有效源码应能再次编译。失败或取消时，上次结果必须标明过期。
9. **项目往返**：导出 ZIP，临时修改项目名，再打开刚导出的 ZIP 并确认替换。核对文件、路径、源码、项目名和主文件均恢复。
10. **布局与生命周期**：在桌面双栏和窄屏中检查编辑/预览切换；刷新、离开页面再返回后，编辑和编译应继续工作。查看控制台是否存在未处理异常。

PDF 图片预览依赖 Ghostscript，不依赖浏览器内置 PDF 插件。还需分别测试缺失 Ghostscript 的提示和 PDF 导出、服务不可用、图片渲染失败/重试；这些边界也有自动回归测试。

本次验收环境：Windows、Chromium 内嵌浏览器、Tectonic 0.17.0、Ghostscript 10.08.0。中文样例使用 `ctex` 的 `fontset=windows`。这不代表已覆盖 Safari、Firefox、移动设备或真实 XeLaTeX 发行版。

可视化恢复验收：实际在纸面修改标题、正文、粗体、标题级别与公式，下载的 `.tex` 包含全部改动且导言区/尾注及引用命令保持原样；再编译并读取实际下载 PDF，确认修改进入排版结果。当前用户项目在独立测试前后逐文件比较，内容不变。窄屏从 PDF 预览选择文档会返回编辑区。

公式和引用专项验收：单击公式打开 MathLive，通过分数按钮及分子/分母占位框将公式改为 1/2；修改 equation 内容及标签，修改两行 align 的末行内容及标签，确认光标默认位于最后一格内。直接修改正文标签、选择交叉引用目标、替换两处相同文献引用中的第二处，全程不切源码。验证取消、撤销、重做、刷新恢复和长引用卡片点击。实际下载 TeX 保留导言区和尾注；编译 PDF 正确显示方程 (1)、(2)、(3)，引用 (1)/(3) 和文献 [1]/[2]。用户当前项目刷新前后 4 个文件逐字节相同。

高级输入与图形输入切换须保留新标签、编号和注释；未修改即确认须保留原始公式，不以数学组件的归一化结果覆盖原文。两项都有事件回归。内嵌浏览器仅允许 HTTP/HTTPS，本次未实跑 file:// UI；本地资源、字体白名单及打包完整性有自动检查。

前端改版验收：在 1280×720 和 1383×1084 的真实浏览器检查工具栏、文稿、引用及公式弹窗、双栏 PDF；确认公式按钮固定可见，原有引用点击、源码/可视化切换、公式保存/撤销和 PDF 下载均工作。多行公式 Ctrl/Cmd+Enter 须先阻止数学组件的插行快捷键再确认，输出不能多出占位行；普通 Enter 仍可编辑矩阵行。已有事件回归覆盖这一区别。用户当前项目 4 文件前后逐字节不变。
